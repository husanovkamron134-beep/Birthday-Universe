# Birthday Universe

A cinematic, interactive 3D birthday experience built with Three.js.

## Run locally

Open `index.html` in a modern browser. The page loads Three.js from a CDN, so an internet connection is required.

## Customize

Open `index.html` and edit the `CONFIG` object near the top of the script: recipient name, sender name, birthday message, and the reveal text.

The scene is an original implementation; no third-party project assets are bundled.
