# Birthday Universe — Cinematic Edition

Haqiqiy kosmik teleskop orqali ko‘rilayotgandek realistik uslubdagi interaktiv 3D tug‘ilgan kun koinoti (Three.js).

## Nimalar bor

- **Markaziy sayyora** — katta, bantli atmosferali gaz giganti, ko‘p qatlamli halqalar va soyasi; bosilganda maxsus tabrik sahnasi ochiladi.
- **7 ta kichik sayyora** — har biri o‘ziga xos shaderda chizilgan (okean, lava, halqali gigant, muz, binafsha, zumrad, pushti-oltin). Hech qanday tayyor tekstura kerak emas.
- **Orbitalar** — markazdan teng masofada, nozik va yorqin; sayyora ortidan nur izi qoladi, har birining tezligi har xil, atrofida mayda zarralar aylanadi.
- **Sayyorani bosganda** — kamera sekin yaqinlashadi, sayyora yorqin nur bilan ajralib turadi, suratlar sayyora ichidan "portal" kabi ochiladi; yopilganda kamera umumiy koinotga qaytadi.
- **Koinot atmosferasi** — moviy, binafsha va oltin tumanliklar, Somon yo‘li, minglab yulduzlar, bloom.
- **Telefonda ham silliq** — qurilmaga qarab sifat avtomatik tanlanadi, FPS pasaysa o‘zi yengillashadi. Portret va landshaft uchun alohida kadrlash.

## Ishga tushirish

`index.html` ni brauzerda oching (Three.js CDN dan yuklanadi, internet kerak). GitHub Pages bilan ham ishlaydi.
